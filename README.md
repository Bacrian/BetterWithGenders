# 

Made for Better Than Adventure (BTA) 8.0.1

# 

**Better With Genders** is a cosmetic mod that adds genders to Minecraft BTA, along with some configurations meant for player customization. It's not meant to be a huge mod with gameplay-changing mechanics, but rather a small addition for further characterization.
